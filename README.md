# ZamoraFest

Aplicación móvil para la gestión y consulta de eventos culturales y festivos de Zamora Chinchipe.

## Estado

Repositorio inicial del proyecto académico. Durante esta fase se desarrollará el backend requerido hasta la Semana 8. La aplicación móvil con Ionic y Capacitor se implementará posteriormente.

## Línea técnica aprobada

- Node.js, TypeScript, Express y npm.
- PostgreSQL con Prisma ORM.
- Zod para validación.
- JWT para autenticación y autorización por roles.
- Swagger/OpenAPI para documentación.
- Vitest y Supertest para pruebas.
- Redis y BullMQ para las optimizaciones de la Semana 8.

## Metodología

El proyecto seguirá Spec-Driven Development (SDD). Cada funcionalidad deberá contar con especificación, plan y tareas aprobadas antes de su implementación.
